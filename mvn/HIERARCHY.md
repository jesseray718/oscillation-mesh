# Oscillation Hierarchy — Minimum Viable Nodes

Oscillation principle: every layer can fall back to the layer below and rise to the layer above.
Physical and digital nodes are modular and interconnectable.

## Layer 0 — Primitive / Survival (zero electricity)
- Local earth, sand, cement, chicken wire / mesh
- Catenary arches & vaults (ferrocement or earth)
- Hand tools only
- Water, food, shelter, heat capture (AeroCement / Black Locust lineage)
- Node = one person + one structure + one tool set

## Layer 1 — Low-tech Open Source
- Meshtastic LoRa node (Heltec / LilyGO / RAK / scavenged solar light enclosure)
- TinyGS firmware on the same hardware → satellite telemetry
- Syncthing over any available link (USB, Wi-Fi, eventual radio bridge)
- Paper + permanent marker backups of critical seeds
- Node = one radio + one solar panel + one battery + one antenna

## Layer 2 — Appropriate Modern
- Reticulum or full mesh routing
- Local LLM (phone / OptiPlex)
- CodeRabbit + shadow epistemology + frozen Agape core
- Syncthing mesh as permanent file backbone
- Node = Layer 1 + compute + versioned knowledge

## Interconnect rules
- Every modern node must be able to drop to Layer 1 or 0 without losing the ability to serve the lowest node.
- Physical ferrocement vaults can house the radios and batteries.
- Digital seeds (context_bridge, ledger, session_seeds) stay readable offline.
- Oscillation is intentional: build modern, test by removing modern, keep what still works.
