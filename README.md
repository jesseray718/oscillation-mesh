# Oscillation Mesh

Hierarchical Minimum Viable Nodes that oscillate between
primitive survival technology and modern open-source appropriate technology.

Layers:
0. Primitive (ferrocement catenary vaults, hand tools)
1. Low-tech (Meshtastic + TinyGS on scavenged solar hardware + Syncthing)
2. Modern (local LLM, CodeRabbit, shadow epistemology, Reticulum)

All nodes modular and interconnectable.
See mvn/HIERARCHY.md, field-guides/, language/SEVEN.md, credits/CREDITS.md.

Built for the lowest node first.
η = useful_joules / human_joules
R → 1.0
