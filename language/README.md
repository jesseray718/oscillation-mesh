# 7-Symbol Calculator & Language

Glyphs:
  ● NODE     ─ LINK     ≈ ENERGY     □ STORE
  → RETURN   ○ OBSERVE  ✧ TRANSFORM

## Usage
  python3 language/seven.py                  # status
  python3 language/seven.py '● ≈ 5 □'        # node stores energy 5
  python3 language/seven.py '○ ✧ ✧'          # observe then compound twice
  python3 language/seven.py deltaT 120       # black-core ΔT for 120 W absorbed

## Black-core + vacuum
See physics/BLACK_CORE_VACUUM.md
